# Apps

Acá vive **toda app, script, dashboard o automatización** que el asistente cree para vos.

Cada una en su propia subcarpeta: `Apps/[nombre-app]/`.

Ejemplos de lo que podrías tener acá con el tiempo:
- Un dashboard que lee una planilla y muestra tu estado financiero.
- Un script que genera reportes semanales.
- Rutinas programadas (tareas que corren solas).

> Regla: nada de apps en la raíz del repo. Todo bajo `Apps/`.
